# Test Strategy

## Objective
To validate the functional, regression, and API behaviour of an e-commerce application
using a risk-based testing approach aligned with ISTQB principles.

## Scope
- In Scope:
  - Login
  - Product selection
  - Cart operations
  - Checkout (happy path)
- Out of Scope:
  - Performance testing
  - Security testing

## Test Levels
- Functional Testing
- Regression Testing
- User Acceptance Testing (UAT – simulated)

## Test Types
- Manual Testing
- Automated UI Testing (Ruby + Selenium)
- API Testing (Postman)

## Test Environment
- Browser: Chrome
- OS: Windows
- Test Data: Standard user credentials

## Entry & Exit Criteria
- Entry: Stable build available
- Exit: All critical test cases passed, no open high-severity defects
